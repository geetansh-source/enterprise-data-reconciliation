# Data files

These three sources were provided as practice data for the capstone project of the iStudio Data Analytics Internship.

| File | What it is |
|---|---|
| `enterprise_database.db` | SQLite database. Table `users` holds the **history** of every customer's status (47,464 rows, 25,000 unique customers). |
| `server_logs.txt` | 100,000 raw server-log lines in one text column (`Raw_Server_Log`). INFO lines are purchases, ERROR lines are failed events. |
| `daily_exchange_rates.csv` | Daily EUR to USD rate for 2023. 104 days (all Fridays and Saturdays) have a blank rate. |
